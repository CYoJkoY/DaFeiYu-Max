WINDOWS · MACOS × MAGPIE

蓝色大肥鱼桌宠DaFeiYu desktop pet

把 Magpie 的实时状态，变成桌边的陪伴。Magpie's live status, as a companion on your desktop.

本页只是使用指南This page is only a guide

桌宠是需要另外下载的独立 App。安装这个插件不会安装、下载或启动它。The desktop pet is a separate app that you download yourself. Installing this plugin does not install, download or start the app.

App 能显示什么What the app shows

  • 几个进行中的请求，就亮几盏灯。One bulb per request in progress.
  • 订阅显示额度百分比，API 钱包显示余额，每一项都能单独开关。Quota percentages for subscriptions and balances for API wallets, each with its own switch.
  • 93 段透明动画，可拖到屏幕边缘。93 transparent animations; drag it to a screen edge.

安装桌面 AppInstall the app

  1. 在浏览器中打开发布页，下载与系统匹配的压缩包：Windows 10+ x64，或 macOS 12+ 的 Apple Silicon Mac。Open the release page in your browser and download the ZIP for your system: Windows 10+ x64, or Apple Silicon Mac with macOS 12+.
  2. macOS：解压后把 App 拖入「应用程序」。Windows：解压后直接运行 BlueDaFeiYu.exe，压缩包不含安装器。macOS: unzip and drag the app to Applications. Windows: unzip and run BlueDaFeiYu.exe directly; the ZIP has no installer.
  3. 在本机 Magpie 运行时启动 App。Start the app while Magpie runs on this computer.

macOS 版仅 ad-hoc 签名，未公证；Windows 版未签名。首次打开前请先核对来源。The macOS build is ad-hoc signed only, not notarized; the Windows build is unsigned. Check the source before opening it the first time.

它如何读取 MagpieHow it talks to Magpie

App 只读取本机 Magpie（127.0.0.1）：请求状态每 2 秒一次，额度卡片每 30 秒一次。请求时带上 magpie-dafeiyu，若设置了 MAGPIE_API_KEY 则带上它。本页不读取任何数据。The app reads Magpie on this computer only (127.0.0.1): request status every 2 seconds, quota cards every 30 seconds. It sends the token magpie-dafeiyu, or MAGPIE_API_KEY when you set one. This page reads nothing.
