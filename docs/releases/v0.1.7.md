# 蓝色大肥鱼 v0.1.7 · 插件市场，自己写的 Zig 插件直接跑

- 新增脚本插件：用 Zig 写 `main.zig`，面板「安装本地插件」选中它，应用用本机 Zig 编译成 WASM，先回灌沙箱验证再装进本地插件目录。**全程不上传**；找不到 Zig 或模块答不上 ABI 时不会留下半个插件。
- 新增插件市场：读取独立的 `DaFeiYu-Max-Plugins` 仓库索引，安装前校验路径、大小与 SHA-256，通过后才落盘；安装来源记录在 `plugin-market.json`，面板区分「本地」与「市场」，可单独启停、卸载。
- 插件在独立 worker 沙箱中运行，只能提交桌宠动作、桥接请求与状态意图，由应用按 `pet` / `bridge` / `net` 权限逐条审查后执行；调用超时 5 秒即终止，崩溃不影响主程序。
- 新增「刷抖音」示例插件（`douyin-scroll`）：通过本机桥接读取推荐流，按兴趣挑一条念给桌宠听，可设置刷新间隔与兴趣优先；不点赞、不评论、不发送。
- 卸载插件时一并删除它的状态文件与本地设置，重装从默认值开始。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.7-Windows-x64.zip`（解压后直接运行 `BlueDaFeiYu.exe`，压缩包不含安装器）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.7-macOS-arm64.zip`（解压后拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
