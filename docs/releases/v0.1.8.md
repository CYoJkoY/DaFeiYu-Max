# 蓝色大肥鱼 v0.1.8 · 界面重写为 Flutter

- 界面运行时由 Electron 重写为 Flutter：桌宠窗口、动画播放、请求灯泡、额度徽章与面板共用同一份 `lib/` Dart 代码，Windows x64 与 Apple Silicon macOS 继续共用一套实现。
- 面板的标题栏与最小化 / 最大化 / 关闭按钮改为应用自绘，配色跟随角色主题，不再显示系统原生窗口按钮。
- 修正面板客户区尺寸：可调整大小的无边框窗口带有隐形边框，之前按外框设定，内容区被压小；现在按客户区设定，卡片与滚动布局不再拥挤。
- 面板截图与渲染的透明边缘不再出现彩色描边。
- 构建、测试与打包工具链收敛到 Flutter（`flutter analyze` / `flutter test` / `flutter build`）；仓库移除 Node、npm 与 Zig 步骤，也不再包含 JavaScript / TypeScript 源文件。
- 脚本插件运行时、插件市场与社交摘要暂未迁移：面板保留已安装插件的启停与节日装扮，市场标注「未开放」，社交摘要标注「未启用」。
- 106 段角色动画随仓库提供，构建时不再需要联网下载素材。其中「吃早餐」的上游视频没有透明通道，已按同一素材重新抠掉背景并保持其余 105 段不变；冒烟测试会专门播放它并截图，防止透明舞台重新变成黑底。
- 产物命名与便携方式不变：Windows 解压后直接运行 `BlueDaFeiYu.exe`；macOS 为「蓝色大肥鱼.app」。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.8-Windows-x64.zip`（解压后直接运行 `BlueDaFeiYu.exe`，压缩包不含安装器）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.8-macOS-arm64.zip`（解压后把「蓝色大肥鱼.app」拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
