# 蓝色大肥鱼 v0.1.10 · 插件市场接回 Flutter 版

- 面板的「插件市场」从占位提示变成真的能用：读取同级插件仓库 `CYoJkoY/DaFeiYu-Max-Plugins` 的 `index.json`，列出条目，可以「刷新市场」「打开市场仓库」。
- 一次安装的流程是：按索引下载清单 → 下载 WASM 模块 → 核对长度与 SHA-256 → 先写进 `plugins/.staging-<id>/`，成功后再整目录改名。任何一步失败都不写盘，磁盘上不会留下半个插件。
- 索引解析与条目校验集中在 `lib/core/market.dart`（纯函数，可单测）：索引上限 512 KB、清单上限 64 KB、`schemaVersion` 必须为 1、`id` / `version` 格式、`permissions` 只能取 `pet` / `bridge` / `net`、`size` 与 `sha256` 的范围，并对 `manifest` / `wasm` 路径做 `sanitizeMarketPath` 校验，拒绝绝对路径、`..`、反斜杠与 URL scheme。
- 装进来的插件记在 `<应用数据目录>/plugin-market.json`，因此市场只会更新、只删除自己装的东西；手工拷进 `plugins/` 的插件照常显示，不会被误判成市场来源。
- 市场卡片与「外观与插件」列表都支持卸载，卸载连同暂存目录一起清掉。
- **脚本插件运行时仍未迁移**：装进来的 `kind: script` 插件会出现在「外观与插件」里并标注「已安装 · 运行时未接入」，本版不会加载或执行它们，也不提供启用开关。这一条同时写在面板卡片底部和 [docs/plugin-market.md](https://github.com/CYoJkoY/DaFeiYu-Max/blob/main/docs/plugin-market.md) 里。
- 插件仓库一侧同步补上了契约的另一半：`scripts/validate.ts` 复刻本应用的接受规则，`README.md` 写明「Flutter 版只做安装与校验」，两边任一放宽都必须同时改。
- 仓库约定不变：语言上限仍是 Dart + Zig + TypeScript，主应用纯 Dart；GitHub 仓库页的语言条恢复按 linguist 默认规则统计，不做任何排除或隐藏。
- 产物命名与便携方式不变：Windows 解压后直接运行 `BlueDaFeiYu.exe`；macOS 为「蓝色大肥鱼.app」。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.10-Windows-x64.zip`（解压后直接运行 `BlueDaFeiYu.exe`，压缩包不含安装器）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.10-macOS-arm64.zip`（解压后把「蓝色大肥鱼.app」拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
