# 蓝色大肥鱼 v0.1.9 · 更小的安装包

- 删除 13 段从未被引用的动画素材（东张西望、螃蟹走路、原地左转奔跑、原地漂浮踏步、6 段「余额-」系列、3 段「碎碎念-」系列），并从 `assets/catalog.json` 同步移除对应名称；实际可播放的 93 段动画、点击回应、状态动画与拖拽反馈全部保留，行为不变。
- 图标母版目录 `assets/brand/` 不再打包进应用，母版文件继续留在仓库供换图使用；README 与第三方声明里的引用不受影响。
- 面板、README、Magpie 页面与测试中的动画数量描述统一为 93 段，与随包内容一致。
- 本轮没有对任何保留下来的 WebP 做重编码、降分辨率或降帧率，画面与 v0.1.8 完全相同。
- 产物命名与便携方式不变：Windows 解压后直接运行 `BlueDaFeiYu.exe`；macOS 为「蓝色大肥鱼.app」。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.9-Windows-x64.zip`（解压后直接运行 `BlueDaFeiYu.exe`，压缩包不含安装器）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.9-macOS-arm64.zip`（解压后把「蓝色大肥鱼.app」拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
