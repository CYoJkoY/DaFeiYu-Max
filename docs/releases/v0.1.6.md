# 蓝色大肥鱼 v0.1.6 · 全 TypeScript + Zig，Magpie 页面零脚本

- 应用运行时、构建、图标、素材下载、测试与打包全部改为 TypeScript，原生能力由 Zig 编写的 `native/src/petkit.zig` 提供；Python、旧 `.mjs`/`.cjs` 源脚本与 `install.ps1` 安装器都已移除。
- 仓库不再包含任何 JavaScript 源文件或生成物。新增的全仓库扫描测试会在出现 `.js`/`.cjs`/`.mjs`/`.py`/`.ps1` 等扩展名，或语言集合不再是 TypeScript + Zig 时失败。
- Magpie 插件页重写为纯 HTML + CSS，不加载任何脚本；右上角可手动切换中文 / EN，默认中文。上一版按 Magpie 界面语言自动切换，这一版改为手动切换以换取零脚本页面。
- 修复启动时的竞态问题；请求灯泡、额度面板与本地 Magpie 读取的行为保持不变。
- Windows 产物恢复为纯便携 ZIP：解压后直接运行 `BlueDaFeiYu.exe`，不安装、不创建快捷方式、无需管理员权限、不设开机启动。

## 下载对应版本

- Windows 10+ x64：`magpie-DaFeiYu-v0.1.6-Windows-x64.zip`（解压后直接运行 `BlueDaFeiYu.exe`，压缩包不含安装器）。
- Apple Silicon Mac：`magpie-DaFeiYu-v0.1.6-macOS-arm64.zip`（解压后拖入「应用程序」）。

`SHA256SUMS.txt` 用于检查下载完整性；Source code ZIP 不是应用安装包。

## 安装与签名

Windows 版未签名，SmartScreen 提示时请先核对来源。macOS 版仅 ad-hoc 签名，没有 Developer ID 签名或公证；若被拦截，请核对来源后在「系统设置 → 隐私与安全性」选择「仍要打开」，不要关闭 Gatekeeper。

详细步骤见 [README](https://github.com/wolfvoid/magpie-DaFeiYu#安装)。
